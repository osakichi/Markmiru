# Markmiru 利用ライブラリ／パッケージ一覧

最終更新: 2026-07-05

技術選定・設計の決定（[`技術選定.md`](技術選定.md) / [`アーキテクチャ・画面設計.md`](アーキテクチャ・画面設計.md) / [`スタイル設定設計.md`](スタイル設定設計.md)）に基づく、利用ライブラリの一覧。名称・呼び出し元の層／言語・用途・ライセンスを示す。

> 基本アーキテクチャは **サーバサイドレンダリング（SSR）**（Go-SSR）。UI は Go が `html/template` で生成した HTML／HTML 断片を htmx が DOM に差し替える。描画・サニタイズ・ハイライト・状態管理・HTML 生成をサーバ（Go）が担い、WebView 側の JS は既製ライブラリ（htmx・mermaid.js）と自作 glue.js のみ。フロントエンドのビルド工程（Node/npm）は無い。

> ライセンスはすべて**寛容（permissive）型**で、商用・クローズド配布のアプリへ同梱可能。義務（著作権表示・ライセンス文の同梱）については §4 を参照。

### 1.3 同梱フォント（アセット）

woff2 を `web/assets/fonts/` へ直 vendor し、`web/assets/fonts.css` の `@font-face` で自己ホストする（`//go:embed` で実行バイナリに同梱）。@fontsource のサブセット別 woff2 を取り込んだもの（Noto Sans JP / Noto Serif JP は latin / latin-ext / cyrillic / vietnamese / japanese、Noto Sans Mono は latin / latin-ext のみ。いずれもウェイト 400・700）。@fontsource パッケージ自体（npm）への依存は無い。

| 名称 | 配置 | 用途 | ライセンス |
|------|------|------|-----------|
| Noto Sans JP | `web/assets/fonts/`（woff2） | 本文ゴシック | SIL OFL 1.1 |
| Noto Serif JP | `web/assets/fonts/`（woff2） | 本文明朝 | SIL OFL 1.1 |
| Noto Sans Mono | `web/assets/fonts/`（woff2） | 等幅（コードブロック／編集オーバーレイ） | SIL OFL 1.1 |

| 名称 | 呼び出し元 | 用途 | ライセンス |
|------|-----------|------|-----------|

| Wails CLI | 開発／ビルド | ビルド・各 OS 向けパッケージング（フロントのインストール/ビルドは無し＝`No Install/Build command. Skipping.`） | MIT |

> Node.js / npm / Vite 等のフロントエンドツールチェーンは**使用しない**（フロントのバンドル工程が無いため）。ビルドは「Go＋Wails」のみで完結する（`scripts/build.ps1` / `build.sh`）。

## 3. Go 推移的依存（内部利用）

`go.mod` の `// indirect` 依存はすべて寛容ライセンス（MIT / BSD 系）。主なもの:

- **Chroma** → `github.com/dlclark/regexp2/v2`（MIT）
- **bluemonday** → `github.com/aymerick/douceur`・`github.com/gorilla/css`（BSD 系）
- **Wails v2** → echo / gorilla/websocket / go-webview2 等（MIT / BSD 系）

直接コードを呼び出していない推移的依存の個別掲載は省略する。

## 4. ライセンス遵守メモ

- **共通義務**: MIT / BSD / ISC / 0BSD はいずれも、著作権表示とライセンス文の**同梱**が必要（0BSD は文面上は不要だが表示を残す）。本体＋サードパーティのライセンス文を `LICENSE.md`（リポジトリ直下）に統合し、`//go:embed` で実行バイナリに同梱する（アプリ内「ヘルプ → ライセンス...」で閲覧可）。
- **フォント（SIL OFL 1.1）**: フォントと共に OFL ライセンス文・著作権表示を同梱。予約フォント名（"Noto"）を改変版に使わない。フォント単体での有償販売は不可（アプリ同梱配布は可）。
- **コピーレフト（GPL 等）の依存は無し**。クローズドソースのまま配布可能。
- **推移的依存**: Chroma（regexp2）、bluemonday（douceur / gorilla-css）、mermaid（d3 等）にも依存があるが、いずれも寛容ライセンス。
